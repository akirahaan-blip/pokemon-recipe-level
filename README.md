# 料理カンスト道（ポケモンスリープ）

ポケモンスリープの料理が、**あと何回作ればレシピレベルがカンスト（Lv.70）するか**を
計算するツールです。

**▶ ここから使えます： https://akirahaan-blip.github.io/pokemon-recipe-level/**

スマホでもパソコンでも使えます。入れた数字は、その人の端末の中だけで計算していて、
どこにも送っていません。

---

## 使い方

1. 上のURLを開く（パソコンの手元のファイルから開くときは、
   エクスプローラー → `Claude` フォルダ → `pokemon-recipe-level` フォルダ →
   **`サイトを開く.bat`** をダブルクリック）
2. 山吹色（黄色）の「料理カンスト道」の画面が出れば準備OKです
3. **「料理を選ぶ」** で、レベルを上げたい料理を選ぶ
4. **「今のレシピレベル」** に、ゲームの料理画面に出ている数字を入れる
5. **「フィールドボーナス（％）」** に、今いるリサーチフィールドのエナジーボーナスの数字を入れる
   （例: 41）
6. **「ふだん上げている 大成功の確率（％）」** に、自分の数字を入れる（10〜80）
7. **「1回作ったときの合計エナジー」** に、料理ができあがった画面に出た数字を入れる
   （**大成功じゃないとき**の数字。大成功の数字しかわからないときは 2 でわった数を入れます）
8. 入れたらすぐ、まん中に「○○ 回」と出ます

### 「1回作ったときの合計エナジー」は何のため？

レシピレベルの経験値には、**なべに入れた「あまり食材」のぶんのエナジーも含まれます**。
このあまり食材のぶんは、レシピの種類やレベルからは計算できないので、
実際の数字から逆算しています。

入れると「あまり食材 ○○」と内訳が出ます。**わからなければ空でOK**ですが、
そのときはレシピの分だけで計算するので、回数が多めに出ます。

### 「次のレベルまで あと」の欄について

ゲームでは、料理を作り終わった画面でだけ「次のレベルまであと○○」が見られます。
その数字を覚えていたら入れてください。**わからなければ空のままで大丈夫**です
（空のときは「そのレベルになったばかり」として計算します）。

### 冷蔵庫（この端末が覚えておいてくれる）

**「④ 冷蔵庫」** に料理を入れておくと、**この端末（パソコンやスマホ）が覚えていて**、
次に開いたときもそのまま残っています。カンストまであと何エナジー必要かを、
いくつでも並べて見られます。

| ボタン | できること |
| --- | --- |
| いまの料理を冷蔵庫に入れる | 今えらんでいる料理と、入れた数字をまるごと保存します（同じ料理は上書き） |
| ひらく | その料理の数字を①②に呼びもどして、計算し直します |
| すてる | 冷蔵庫から消します |

また、**最後に入力した内容も覚えている**ので、次に開いたときは前回の続きから始められます。

※ ブラウザのシークレットモードや、Cookie をブロックする設定にしていると覚えられません。
その場合は冷蔵庫のところに注意書きが出ます。

### 「イベント中」のチェックについて

料理のエナジーが増えるイベントのときだけ、**「イベント中」にチェックを入れます**。
チェックを入れると倍率の欄が出てくるので、そこに倍率（よくあるのは 1.5）を入れてください。
ふだんはチェックを外したままでOKです。

## 出てくる数字の意味

| 表示 | 意味 |
| --- | --- |
| ○○ 回 | あと何回作ればカンストするか（**期待値**） |
| 運が良ければ ○回 〜 最大 ○回 | 大成功の出かたしだいで、回数はこの間で前後します |
| 1回の経験値 | 1回作ったときに入る経験値（大成功の分をならした平均） |
| のこりの経験値 | カンストまでに、あとどれだけ経験値がいるか |
| エナジーボーナス | 今のレベルのボーナス → カンストしたときのボーナス |

「レベルごとの内訳」は、見出しをクリックすると開きます
（そのレベルに上がるのに必要な経験値の表。どの料理でも同じです）。

**「期待値」って？**：大成功が出るかどうかは運なので、ぴったり何回とは決まりません。
このツールが出しているのは「**その確率で大成功しながら作りつづけたら、平均こうなる**」
という数字です。これを期待値といいます。
運がよければもっと少なく、悪ければもっと多くなり、その幅もゲージの下に出しています。

## 仕組み（なぜ単純な割り算じゃないのか）

- レシピレベルは「作った回数」ではなく、**その料理で手に入れたエナジーが
  そのまま経験値**になります。
- レベルが上がるとエナジーボーナスが増えるので、**1回でもらえる経験値もどんどん増えます**。
- そのため、このツールは Lv.35 → 36 → 37 …… と、1レベルずつ積み上げて数えています。

### 計算式

```
1回のエナジー = （レシピぶん ＋ あまり食材ぶん）×（1＋フィールドボーナス）× イベント倍率
  レシピぶん = 基本エナジー ×（1＋レシピレベルボーナス）
  ※ あまり食材にはレベルボーナスがかかりません

もらえる経験値 = 1回のエナジー × 大成功のならし倍率
  確率 p で2倍 → ならすと（1 ＋ p）倍

  例）p が 10％のとき … 1.1 倍
  例）p が 80％のとき … 1.8 倍
```

### 大成功の確率について

もともとの確率は **10％**。**料理チャンスS で最大 +70％**（＝80％が上限）。
②の「**ふだん上げている 大成功の確率（％）**」に、自分の数字（10〜80）を入れてください。

### 計算に入れていないこと

- **日曜日の料理大成功のエナジー3倍は入れていません。**
  日曜は大成功の確率も上がり、なべの容量も2倍になりますが、
  最後まで作りきる人が少ないため、あえて計算から外しています。
  日曜にきちんと作れば、ここで出る回数より少なくてすみます。
- あまり食材のぶんは、実際にはその日その日で変わります。入れてもらった数字のまま
  ずっと同じだとして計算しているので、だいたいの目安です。

## データの出どころ

- ポケモンスリープ攻略・検証 Wiki\*「料理」ページ（2026-08-23 に読み取り、Ver.3.7.0 時点）
  - レシピレベルの必要経験値の表（Lv.2〜70）
  - レシピレベルボーナスの表（0％〜258％）
  - 大成功の倍率と確率（2倍・もともと10％／料理チャンスS で最大 +70％）
- レシピ78品の名前と基本エナジーは、となりのフォルダ `pokemon-ryori-navi` で
  同じ Wiki から読み取ったものを使っています。

## ゲームのバージョンが上がったときの直し方

`index.html` をメモ帳で開いて（右クリック →「プログラムから開く」→「メモ帳」）、
下のほうにある `<script>` の中を直します。直したら Ctrl+S で保存し、
ブラウザで F5（再読みこみ）を押してください。

- **料理が増えたとき**
  `const RECIPES = [` のすぐ下に、同じ形で1行足します。
  `  {n:"料理の名前", c:"カレー", t:食材の数, e:基本エナジー},`
  （`c` はカレー／サラダ／デザートのどれか）
- **レベルの上限が上がったとき**
  `const BONUS = [` にボーナス（％）を、`const NEED = [` に必要経験値を、
  それぞれ末尾に足して、`const MAXLV = 70;` の数字を新しい上限に変えます。
